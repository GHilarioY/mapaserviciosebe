# Mapa de Servicios EBE

Mapa interactivo de los 659 locales de Educación Básica Especial del Perú (CEBE, PRITE, CREBE, PANETS), con filtros por servicio, gestión, área, departamento y UGEL, y capas de relieve, satélite y curvas de nivel.

En línea: https://mapaserviciosebe.ghilario.com

Fuente: padrón de locales EBE, ESCALE – MINEDU (corte 09/09/2026). Base cartográfica: Esri, OpenTopoMap y © colaboradores de OpenStreetMap.
